# 🎓 Telegram-бот и Mini App для 11 «Б» класса

Полноценный Telegram-бот с веб-приложением (**Telegram Mini App**) и текстовым меню для управления расписанием уроков, домашними заданиями, переменами и звонками 11 «Б» класса.

---

## 🌟 Основные возможности

### Для учеников:
- 📱 **Telegram Mini App:** Стильное приложение для 11 «Б» прямо в Telegram (календарь уроков, чеклист ДЗ, расписание звонков).
- 💬 **Текстовое меню:** 100% дублирование функций через кнопки в чате.
- 📅 **Расписание уроков 11 «Б»:** Просмотр на Сегодня / Завтра / Всю неделю / Любой день без лишней информации о кабинетах.
- 🔔 **Звонки и перемены:** Расписание звонков с длительностью перемен.
- 📚 **Домашнее задание & Чек-лист:** Просмотр заданий с прикрепленными фото + личный трекер выполнения.
- 🌙 **Ежедневный вечерний дайджест:** Автоматическая рассылка в 18:30 (расписание + ДЗ на завтра).

### Для групп и бесед класса:
- 👥 **Работа в беседах:** Бот отвечает на команды `/schedule`, `/tomorrow`, `/hw`, `/bells`, `/help` (без необходимости выдавать права администратора в группе).
- 🌙 **Авто-дайджест в беседу:** Вечерняя рассылка плана на завтра прямо в общий чат.

### Для администратора (Вас):
- 🛡 **Программная выдача прав:** Ваш Telegram ID указывается в `.env` (`ADMIN_ID`) и автоматически наделяет вас правами администратора. Также вы можете назначать других администраторов кнопками прямо в боте.
- 📅 **Редактор расписания уроков:** Изменение предметов на любой день недели (Пн–Сб) и любой урок прямо через кнопки в чате.
- 🔔 **Редактор звонков:** Быстрое изменение времени уроков и перемен.
- ➕ **Добавление ДЗ:** Пошаговый мастер с прикреплением фото страниц учебников.
- 🔄 **Замены уроков:** Быстрая фиксация замен/отмен с мгновенным оповещением класса.

## 🚀 Быстрый запуск локально

### 1. Клонирование и установка зависимостей
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather).
- `ADMIN_ID` — ваш цифровой Telegram ID (узнать можно в [@userinfobot](https://t.me/userinfobot)).
- `WEBAPP_URL` — ссылка на WebApp (при локальном тесте через ngrok: `https://xxxx.ngrok-free.app/app`, либо оставьте `http://localhost:8000/app`).

### 3. Запуск приложения
```bash
python -m backend.main
```
Сервер запустит одновременно:
1. Базу данных SQLite (автоматически создаст таблицы и начальные предметы).
2. FastAPI веб-сервер на порту `8000`.
3. Telegram-бота в режиме long-polling.
4. Планировщик APScheduler для вечерних рассылок.

## 🌐 Развертывание на бесплатном хостинге Render

1. Загрузите код в ваш **GitHub репозиторий**.
2. Зарегистрируйтесь на [Render.com](https://render.com).
3. Нажмите **New +** -> **Web Service** -> выберите ваш репозиторий.
4. Render автоматически считает конфигурацию из файла `render.yaml` (или укажите):
   - **Environment:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m backend.main`
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` — ваш токен бота
   - `ADMIN_ID` — ваш Telegram ID
   - `WEBAPP_URL` — `https://<ВАШЕ-ИМЯ-СЕРВИСА>.onrender.com/app`
   - `BASE_URL` — `https://<ВАШЕ-ИМЯ-СЕРВИСА>.onrender.com`
6. Нажмите **Deploy Web Service**.

## ⚡ Настройка Cloudflare Worker (Keep-Alive, чтобы Render не засыпал)

Бесплатный Render переходит в спящий режим через 15 минут неактивности. Cloudflare Worker решает эту проблему, отправляя запрос каждые 10 минут:

1. Перейдите в [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Workers & Pages** -> **Create Application**.
2. Вставьте код из файла `cloudflare/worker.js`.
3. В настройках воркера (**Settings** -> **Variables**) добавьте переменную:
   - `RENDER_ORIGIN` = `https://<ВАШЕ-ИМЯ-СЕРВИСА>.onrender.com`
4. В разделе **Triggers** добавьте **Cron Trigger**:
   - `*/10 * * * *` (каждые 10 минут).

## 📱 Настройка кнопки Mini App в Telegram через @BotFather

Чтобы у всех пользователей в левом нижнем углу чата была кнопка «Открыть меню / Mini App»:
1. Напишите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/mybots` -> выберите вашего бота.
3. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Отправьте ссылку на WebApp: `https://<ВАШ-RENDER-URL>.onrender.com/app` (или ваш домен Cloudflare).
5. Введите название кнопки: `📱 Mini App`.
