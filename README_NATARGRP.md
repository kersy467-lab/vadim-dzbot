# ⚔️ natarGRP — Экшен RPG для Mini App 11 «Б»

## 🌟 Что нового и как это устроено:
1. **Экшен-Арена (Soul Knight / Action Roguelike)**:
   - Полноценная 2D боевая арена на HTML5 `<canvas>`.
   - Управление: виртуальный джойстик на мобильном экране (слева) или клавиши **WASD** на ПК.
   - Кнопки действий: ⚔️ Удар/Рубка, ⚡ Ультимейт (скилл), 🧪 Зелье исцеления, 🎯 Авто-бой.
   - Толпы крипов сбегаются со всех сторон, выпадают монеты 🪙 и сферы опыта ✨ с эффектом притягивания (магнит).
   - Анимация дуги рассекающего удара меча, всплывающие цифры урона и критов (`💥 КРИТ! -120`).

2. **Сундуки Награды каждые 10-20 волн**:
   - На 10, 20, 30... волнах спавнится Босс этажа с большой полоской HP.
   - За победу над боссом игрок получает **Наградной Сундук**:
     - 10 волна: Серебряный Сундук (Редкие и Эпические предметы)
     - 20 волна: Золотой Сундук (Эпические и Легендарные предметы)
     - 30+ волна: Мифический Сундук (Легендарные и Бессмертные предметы)
   - Всплывающее окно открытия сундука с анимацией и гарантированным функциональным предметом.

3. **Система 3-х Атрибутов как в Доте**:
   - **Сила**: +22 HP за каждое очко, +0.35 HP/сек регенерация здоровья.
   - **Ловкость**: +2.5% скорости атаки, +0.4 брони, криты и уклонение.
   - **Интеллект**: +14 маны за очко, +0.25 MP/сек регенерация, +0.4% сопротивления магии.
   - **Основной атрибут героя**: дает **+1 к базовому урону атаки** за каждое очко!

4. **Прокачка уровня и очков характеристик**:
   - Исправлен баг прогресса уровня: опыт и шкала прокачки синхронизированы (`xp` и `xp_needed`).
   - За каждый новый уровень герой получает **+5 свободных очков характеристик** для распределения между Силой, Ловкостью и Интеллектом!
   - Также доступна докачка характеристик за нафармленное золото.

5. **Понятные и подписанные шмотки**:
   - Каждый предмет четко подписан: бейдж слота `[Оружие ⚔️]`, `[Броня 🛡️]`, `[Реликвия 💍]`, `[Зелье 🧪]`.
   - Цветовая редкость: `[Обычный]`, `[Редкий]`, `[Эпический]`, `[Легендарный]`, `[Бессмертный]`.
   - Прямой предпросмотр параметров на карточке (`⚔️ +45 Урон | 🛡️ +18 Броня | 💥 +20% Крит`).
   - Кузница Тайной Лавки для заточки шмоток до +99.

6. **Кооператив и Дуэли**:
   - Совместные рейды на боссов (Рогнар Бессмертный, Древний Терзатель, Черный Дракон).
   - 1v1 PvP дуэли между одноклассниками с рейтингом.
   - Таблица лидеров класса 11 «Б».

---

## 🚀 Как запустить для теста локально:
```bash
python backend/main.py
```
Откройте в браузере: `http://localhost:8000/app` -> вкладка «Мини-игры» -> «natarGRP».

## 📦 Как передать изменения однокласснику (хосту бота):
### Вариант 1 (Архив):
Отправьте ему файл `natargrp_quick_update.zip` и распакуйте поверх проекта.

### Вариант 2 (Git Patch):
Если у него git-репозиторий, отправьте `natargrp_update.patch`:
```bash
git apply natargrp_update.patch
```
