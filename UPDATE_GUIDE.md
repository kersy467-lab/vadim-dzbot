# 🛡️ Инструкция по установке обновления Dota 2 RPG для хоста 11 «Б»

Привет! В бота и Mini App было добавлено масштабное обновление: **Dota 2 RPG** (бесконечный фарм крипов, 100+ предметов с заточкой, рейды на Рошана и дуэли 1v1 с одноклассниками).

---

## ⚡ Что изменилось и как это работает?

1. **База данных**:
   - Добавлена новая таблица `rpg_characters` (модели в `backend/db/models.py`).
   - Таблица создается **автоматически** при первом запуске через `init_db()`. Ручных SQL-миграций делать **не нужно**!
2. **Зависимости**:
   - Все зависимости уже есть в стандартном `requirements.txt`. Дополнительных тяжелых библиотек не требуется.
3. **Frontend (Mini App)**:
   - В раздел «🎮 Игры» добавлена вкладка **⚔️ Dota RPG** с прокачкой героев (Pudge, Juggernaut, PA, SF, Invoker, WK, Anti-Mage), инвентарем, Кузницей Рошана, авто-фармом крипов и таблицей лидеров.
   - Поддерживаются прямые инвайты одноклассников в Telegram на рейды боссов и дуэли через бота.

---

## 🚀 Способ 1: Через GitHub Pull Request (Рекомендуемый, 1 минута)

Поскольку твой бот на Render привязан к GitHub и деплоится автоматически:
1. Создай новую ветку или форк:
   ```bash
   git checkout -b feat/dota-rpg
   git add .
   git commit -m "feat: add Dota 2 RPG endless creeps, 100 items, raids and duels"
   git push origin feat/dota-rpg
   ```
2. Открой Pull Request на GitHub в основной репозиторий `k11298379-sudo/dzbot`.
3. Одноклассник нажимает зеленую кнопку **«Merge pull request»** на GitHub.
4. **Render сам за 60 секунд пересоберет и запустит бота с новой игрой!**

---

## 📦 Способ 2: Через Git Patch (в 2 команды)

В корне проекта сформирован готовый файл патча `dota_rpg_update.patch`.
Одноклассник у себя в терминале репозитория запускает:
```bash
git apply dota_rpg_update.patch
git add .
git commit -m "feat: add Dota 2 RPG with endless creeps, items, forge and duels"
git push origin main
```
После этого Render автоматически подхватит коммит и обновит приложение.

## 📂 Способ 3: Скопировать измененные файлы вручную или архивом

Если нужно перенести файлы руками, обновлены/добавлены следующие файлы:

### Новые файлы:
- `backend/api/rpg.py` — REST API для прокачки, фарма крипов, заточки и лидерборда.
- `backend/db/crud/rpg.py` — движок RPG: 7 героев Доты, каталог 100 предметов, формулы критов, дропа и заточки.
- `frontend/js/rpg.js` — весь интерфейс игры, боевка, Кузница, рейды и дуэли.
- `tests/test_rpg_game.py` — автоматические тесты всего функционала RPG.

### Измененные файлы:
- `backend/db/models.py` — добавлена модель `RPGCharacter`.
- `backend/db/crud/__init__.py` — экспорт функций RPG.
- `backend/api/game_rooms.py` — добавлены комнаты `RPGPvPRoom` и `RPGCoopBossRoom`.
- `backend/api/routes.py` — регистрация роутера `/api/rpg` и уведомления в Telegram.
- `frontend/index.html` — подключение скрипта `rpg.js`.
- `frontend/js/api.js` — клиентские API-методы для RPG.
- `frontend/js/games.js` — интеграция вкладки Dota RPG и открытие дуэлей/рейдов по ссылке.

## 🔒 Важное напоминание по безопасности для хоста!

В репозитории в `backend/config.py` и `render.yaml` открыто лежат пароль от базы Neon PostgreSQL и ключ Google Gemini. 
**Рекомендация:**
1. Перенесите `DATABASE_URL` и `GEMINI_API_KEY` в панель управления **Render Dashboard -> Environment**.
2. В файлах кода оставьте чтение через `os.getenv(...)`.
3. Смените пароль к Neon и сгенерируйте новый ключ Gemini, чтобы никто посторонний не получил доступ к базе.
