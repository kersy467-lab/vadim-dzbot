# Перерождение: упрощение и сохранение акций — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Упростить перерождение, заранее сообщать о нём игрокам, сохранить акции и дивиденды с падением котировки на 99%, а действие сделать заметным.

**Architecture:** `RebirthService` управляет доступом к объявлению и сбросом; миграция добавляет отметку уже отправленного этапа и коэффициент переоценки акций. `company_reset_v2` сохраняет биржевой выпуск и выплаты только при перерождении, закрывает заявки с возвратом эскроу и оставляет обычный сброс без изменений. Frontend добавляет раннюю карточку и верхние действия.

**Tech Stack:** Python, FastAPI, SQLAlchemy async, Telegram bot, vanilla JavaScript, Tailwind classes.
